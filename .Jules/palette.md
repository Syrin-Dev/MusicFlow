## 2024-05-18 - Dynamic ARIA Labels on Icon-only Media Controls
**Learning:** Icon-only media controls that convey interaction state (e.g., Play/Pause, Shuffle, Repeat) must have dynamically updating `aria-label` attributes to accurately communicate the state to screen readers. Relying solely on visual icons or static labels creates severe accessibility gaps. Custom `div`-based sliders also require explicit ARIA roles (`role="slider"`), standard slider attributes (`aria-valuemin`, `aria-valuemax`, `aria-valuenow`), `tabIndex={0}`, and `onKeyDown` handlers for full keyboard usability.
**Action:** Always ensure that any stateful toggle button uses a dynamic `aria-label` (e.g., `aria-label={isPlaying ? 'Pause' : 'Play'}`) and hides the decorative icon (`aria-hidden="true"`). Fully instrument custom div sliders with appropriate ARIA roles and keyboard events.
