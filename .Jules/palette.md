## 2024-07-05 - Accessible Ligature Icons and Custom Sliders
**Learning:** When using font-based ligature icons (like material-icons), screen readers will read the literal text (e.g., "play arrow", "skip next") if not explicitly hidden, causing confusing navigation. Additionally, custom ARIA sliders built from `div` elements require strict keyboard event handling (like `onKeyDown` for Arrow keys), `tabIndex={0}`, and appropriate ARIA attributes to be usable by keyboard and screen reader users. However, adding focus rings to custom sliders can cause visual clipping if the parent container uses `overflow-hidden`.
**Action:** Always wrap ligature text in a `<span aria-hidden="true">` and provide a descriptive `aria-label` on the interactive parent button. For custom sliders, implement full keyboard navigation (ArrowLeft/ArrowRight), apply project-standard focus rings (`focus-visible:ring-2 focus-visible:ring-[#8B5CF6]`), remove `overflow-hidden` on parents, and use `rounded-full` on child tracks to safely bound active states without clipping the focus indicator.
