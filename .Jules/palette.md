## 2024-03-31 - Keyboard Accessibility in Track Grids
**Learning:** Found an accessibility anti-pattern in `RecommendedGrid.tsx` where complex interactive elements (track cards) and their internal action buttons (Play/Share) relied strictly on mouse hover (`group-hover:opacity-100`), making them completely invisible and unusable for keyboard navigation and screen readers. Wrapping clickable divs without `role="button"`, `tabIndex={0}`, or `onKeyDown` handlers prevents them from receiving focus.
**Action:** Always add semantic structural attributes (`role="button"`, `tabIndex={0}`, `aria-label`, `onKeyDown`) to custom interactive elements. Crucially, when hiding inner actions until hover, pair `group-hover` with `group-focus-within` and ensure child elements use `focus-visible` styles so that tabbing into the component makes the hidden actions visible and accessible.
