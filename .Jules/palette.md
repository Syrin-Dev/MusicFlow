## 2026-06-20 - Custom Interactive UI Sliders Require Specific Focus Handling\n**Learning:** When creating custom ARIA sliders (like the audio seek bar) replacing native inputs, you must add specific keyboard event handlers (ArrowLeft/ArrowRight) and `tabIndex={0}`. More importantly, if the container uses `overflow-hidden`, it will visually clip the standard Tailwind focus rings (like `focus-visible:ring-2`), making keyboard focus invisible to sighted users.\n**Action:** Always verify custom interactive components without `overflow-hidden` or apply padding/margins to ensure focus rings remain fully visible when building custom slider or toggle inputs.
