## 2024-05-18 - Making Custom Sliders and Media Controls Accessible
**Learning:** Custom div-based components, such as custom seek sliders and generic media control buttons, frequently lack core semantic behavior. Using raw icons inside a `<button>` tag will read out as generic "button" to screen readers without an explicit `aria-label`. Moreover, complex visual widgets like progress bars used for media seeking require the `slider` role, `tabIndex={0}`, and programmatic ARIA bindings (`aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-valuetext`) coupled with an `onKeyDown` handler to allow keyboard adjustments. Visual indicators, like focus rings (`focus-visible:ring-2`), are also vital for keyboard users to see which component they are interacting with.
**Action:** When creating custom interactive media elements, always bind `aria-label`, update `aria-pressed` for togglable states, explicitly define proper `role` and `aria-value*` attributes for slider interfaces, implement keyboard navigation (e.g., `ArrowLeft` / `ArrowRight`), and ensure custom visual focus states are present.
