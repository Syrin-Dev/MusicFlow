## 2026-05-06 - Added proper ARIA states and keyboard navigation to media playback controls\n**Learning:** The PlayerBar component lacked standard media control accessibility. For custom seek bars built with `div`, using `role="slider"` with `tabIndex={0}`, min/max/now ARIA values, and implementing Arrow Left/Right keyboard navigation via `onKeyDown` makes it usable for screen readers and keyboard users. Additionally, when using Material Icons inside buttons, the text content of the icon is read aloud by screen readers; therefore, the icon should have `aria-hidden="true"` and the button should have a dynamic `aria-label` (e.g., 'Play'/'Pause' or 'Mute'/'Unmute').\n**Action:** Apply this pattern to all custom sliders and icon-only buttons across the application.
