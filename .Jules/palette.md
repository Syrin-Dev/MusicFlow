## 2024-07-07 - Custom Sliders and Keyboard Access
**Learning:** Custom UI sliders (like playback progress bars) built with generic `<div>` containers inherently lack keyboard accessibility. Using `overflow-hidden` on such containers will clip focus ring indicators like `focus-visible:ring-2`. When implementing keyboard seeking, using absolute value increments (e.g., +/- 5 seconds) is preferred over percentage-based calculations for accurate temporal navigation.
**Action:** When creating or fixing custom slider components, ensure to remove `overflow-hidden` if using external focus rings, manually add `role="slider"`, `tabIndex={0}`, and required `aria-value*` attributes. Furthermore, always provide an `onKeyDown` handler mapping `ArrowRight` and `ArrowLeft` keys to navigate the slider's value logically.
