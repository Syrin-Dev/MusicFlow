## 2024-05-04 - Search Bar Webkit Cancel Button Duplicate Fix\n**Learning:** When creating a custom 'clear search' button for an `<input type="search">`, Webkit browsers (Safari, Chrome) will natively inject their own cancel button, resulting in duplicate 'X' buttons which is a confusing UX.\n**Action:** Use the Tailwind selector `[&::-webkit-search-cancel-button]:hidden` to consistently suppress the native browser button when providing a custom clear UI.
