## 2024-10-24 - Accessible Sliders and Icon Buttons
**Learning:** Custom UI sliders require extensive ARIA attributes (`role="slider"`, `tabIndex={0}`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-valuetext`) and `onKeyDown` handlers for `ArrowRight`/`ArrowLeft` to be keyboard accessible. Also, `overflow-hidden` on slider containers can clip focus rings (`focus-visible:ring-2`). Interactive icon-only buttons need `aria-label`, `aria-pressed` (for toggles), and `aria-hidden="true"` on the child icon element (especially for ligature fonts) to prevent screen readers from reading the literal text like "play_arrow".
**Action:** Always verify focus rings are not clipped by parent `overflow` properties, strictly add complete ARIA attribute sets and keyboard handlers to custom interactive elements, and add `aria-hidden="true"` to icon ligatures.
