## 2024-03-24 - Accessible Custom Search Bars in Webkit
**Learning:** When using `<input type="search">` to improve accessibility for custom search components in Webkit environments, browsers like Safari/Chrome will automatically inject a default clear ('X') button. If your component already implements a custom clear button, this results in duplicate controls which is confusing for users and screen readers.
**Action:** Always combine `<input type="search">` with the CSS rule `[&::-webkit-search-cancel-button]:hidden` (Tailwind syntax) or `::-webkit-search-cancel-button { display: none; }` to suppress the native control when providing a custom clear button. Additionally, ensure the containing form has `role="search"` and the input has a properly linked visually hidden label.
